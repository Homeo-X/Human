# Data Management Plan

## Dataset Register
| Dataset | Source (generated by EXP / external) | Format | Size (order) | License / Ethics | Retention |
|---|---|---|---|---|---|

## Provenance Chain
_Every figure and claim must walk backward: figure ← analysis output ←
processed data ← raw data ← run (EXP id, code version, seed, params).
State the mechanism (directory convention, metadata files, workflow tool)
— not the aspiration._
| Stage | Location/Convention | Metadata Captured |
|---|---|---|
| raw | | EXP id, seed, code version, params, timestamp |
| processed | | script + version that produced it |
| analysis outputs / figures | | notebook/script + input hashes |

## Storage & Backup
Where each stage lives, capacity vs the EXP resource budgets, backup
policy for the irreplaceable (raw runs are irreplaceable; figures aren't).

## Sharing & Archival
What is published (data, code, both), where (repository/DOI), when
(embargo?), and in what form external reproduction is supported.

## Testable Requirements
| ID | Priority | Requirement | Acceptance Criteria (Given/When/Then) | Notes |
|---|---|---|---|---|
| FR-DATA-001 | Must | Every raw output carries the full provenance metadata row | Given any raw file, when inspected, then EXP id, seed, code version, and params are recoverable from it or its sidecar | |
| FR-DATA-002 | Must | Processed data regenerable from raw by recorded scripts | Given raw data and the repo, when the pipeline reruns, then processed outputs match (bit-exact or within declared tolerance) | |
| FR-DATA-003 | Must | Figure-to-run traceability | Given any figure in the writeup, when traced, then the producing runs (EXP, seeds) are identifiable | |
