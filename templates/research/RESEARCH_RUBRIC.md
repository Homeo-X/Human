# Research Rubric

_Known ways studies go wrong before data arrives. Protocol identical to
the game DESIGN_RUBRIC: every item dispositioned — **pass** (one line of
evidence), **flag** (punch-list item), **N/A** (reason) — into
`docs/RES_Methods_Review.md` during pass A; surviving flags require a
Decision Log entry. Silence is not a disposition._

| ID | Check | How to Verify |
|---|---|---|
| RRB-01 | A hypothesis nothing could kill | HYP register's "What Would Kill It" column non-empty and real |
| RRB-02 | HARKing risk: no pre-registered criteria before runs | Analysis_Plan freeze Decision predates main-run start |
| RRB-03 | Exploratory findings positioned as confirmatory | HYP types honest; exploratory charter present |
| RRB-04 | A named construct never operationalized | Charter constructs table covers every load-bearing term in HYPs |
| RRB-05 | Candidate confounds unnamed | Methodology threat register names specific confounds, not the category |
| RRB-06 | Sample/run counts without any justification | every EXP condition row has its "why that number" |
| RRB-07 | Baseline strawmanning | controls table's fairness column: baselines tuned as hard as treatments |
| RRB-08 | Seed cherry-picking exposure | seed policy forbids post-hoc selection; robustness table includes seed sensitivity |
| RRB-09 | Metric defined after seeing runs | EXP metrics tables dated/frozen with the Analysis freeze |
| RRB-10 | Garden of forking paths: exclusions/stopping decided ad hoc | stopping & exclusion rules pre-stated; applications logged |
| RRB-11 | The null branch is empty | every EXP interpretation map includes the null row; Charter's refuted-branch contribution non-empty |
| RRB-12 | Multiple comparisons unaddressed | Analysis_Plan posture stated |
| RRB-13 | Provenance chain aspirational, not mechanical | Data_Management names the mechanism; FR-DATA-001..003 present |
| RRB-14 | Reproduction target undeclared or untested | Reproducibility levels declared; FR-REPR rows with criteria |
| RRB-15 | Code changed between experiments without declaration | cross-experiment rules honored; diffs → Decision Log |
| RRB-16 | Study-type lens extra-depth docs left skeletal | lens row vs actual depth (mirror of RUB-25) |
| RRB-17 | A causal word in a HYP with no CM row and estimand | Charter HYP wording vs Methodology's causal model tables |
| RRB-18 | Power/precision numbers absent or circular | Power section sources its variance assumption; EXP counts cite it |
| RRB-19 | Causal claim from a design that can't license it | estimand's "identified by" column names a real design feature, not hope |
| RRB-20 | Broken trace chain | specgraph unreferenced-HYP/DC warnings are zero, or each names its open question |
