# Biological Research Charter

_What biological question this model exists to answer, whose body it represents,
and the boundary of what it may claim. Written before the ontology, because the
ontology's shape follows from the question._

## The Modelling Question
_One paragraph: what a user should be able to know, spatially, mechanistically,
and quantitatively, that they could not know before._

## The Reference Subject
_Whose body is this? State explicitly — the reference is never "a human", it is
always some population, some age, some sex, some state._
