# Game Concept

## High Concept
_One sentence a stranger repeats correctly. "X meets Y" is allowed only if
followed by what's genuinely new._

## Design Pillars
_2–4 pillars. Every later design decision must serve at least one; a
feature serving none is cut by default. Pillars are tie-breakers, so they
must be able to conflict with something (a pillar nothing could violate is
a platitude)._
